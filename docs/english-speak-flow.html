诊断

你卡的不是框架，是「翻目录」

话术手册把表达拆成 10 组，复习时很清晰；但真实对话里，外教问完你只有 1–2 秒。这时如果还在想「这是转折还是条件？宁可还是万一？」，大脑在做检索，不是在做表达。

以前 · 开口瞬间

外教问完 → 脑子打开话术手册目录 → ①转折 ②条件 ③因果…挨个比对 → 还没选中，对方已经在等 → 只好蹦单词或沉默。

现在 · 开口瞬间

外教问完 → 只问「这一轮我要干什么」→ 落进 6 个意图之一 → 取出该意图的默认骨架 → 把中文意思塞进 X/Y → 开口。

转变的本质：从「在 60 个框架里找答案」变成「在 6 个意图里选配方」。手册仍要，但是课后查的；开口时只带口袋里的 6 条默认骨架。
核心

开口前只问自己一句

1 秒决策
Decision Question
这一轮，我要干什么？
不是「英文怎么说」，而是「我这一句的任务是什么」——表态、选择、解释、担心、立底线，还是卡壳重说？
表态
我同意 / 我不完全同意 / 我觉得…
选择
两害相权 / 我宁可…
解释
为什么这么做 / 给理由
担心
万一…呢？提出风险
底线
只要…我就… / 无论如何
卡壳
句子说砸了，换说法重来
地图

6 意图 → 默认骨架

开口只记左栏 + 中间列
每个意图只绑一条默认骨架。其余框架（even though / unless / let alone…）是词典里的升级选项——课后查、熟练后再换，开口时不要临时升级。
意图默认骨架（先死背）什么时候用
① 表态给看法 / 软反驳
I know X, but Y.
升级：On the surface X, but deep down Y.
 对方已有观点，你要补充或温和不同意
② 选择取舍 / 偏好
I'd rather X than Y.
升级：Rather than X, I'd rather Y.
 外教问 why this / why not that
③ 解释给理由
Y, because X. / X, so Y.
口语神器：…after all.（句尾补理由）
 对方问 why；或你要先抛结论再补因
④ 担心提风险
What if X?
升级：Even if X, … / What if there's a chance?
 你想把话题从「眼前」拉到「万一」
⑤ 底线条件 / 承诺
As long as X, I'll Y.
升级：No matter what, I'll Y.
 谈原则、谈「什么情况下我做什么」
⑥ 卡壳自救重说
I mean… / In other words, …
也可：Actually… / To be honest…
 说了一半卡住，或刚说的不够清楚
💡 硬规则：开口瞬间只允许用「默认骨架」。想用升级版？课后在 话术手册 里查对应组，下次再换——不要当场开卷考试。
流程

5 秒组装法

定意图 → 套骨架 → 填槽
1

定意图（≈1 秒）

用中文在心里点一下：表态 / 选择 / 解释 / 担心 / 底线 / 卡壳。点不中就默认用 I know X, but Y（万能表态）。

2

套骨架（≈1 秒）

把对应骨架整句调出来——此时还不要纠结单词，先让句型站稳。骨架比词汇更重要。

3

填 X / Y（≈3 秒）

把你的中文意思塞进空位。词不会就用简单词（good / bad / hard / important）。说完再用 I mean… 补一层细节。

💡 防拖延口令：骨架先出声，单词后补齐。宁可说 "I'd rather be safe than sorry." 这种糙句，也不要为了找「精准词」沉默 5 秒。
实操

外教场景 · 完整组装演示

看一遍流程，再自己复述
下面每条都按「外教问 → 意图 → 骨架 → 成句」走一遍。练的时候盖住最后一行英文，自己先说。
外教：“Do you like living in a big city?”
中文想法热闹是热闹，但有时候太吵、太累
意图① 表态（先承认优点，再讲真实感受）
骨架I know X, but Y.
成句I know big cities are convenient, but sometimes they're just too noisy and tiring.
外教：“Why don’t you just quit and find another job?”
中文想法与其现在裸辞瞎找，不如先攒经验再走
意图② 选择
骨架I'd rather X than Y.
成句I'd rather build more experience first than quit with nothing lined up.
外教：“Why are you studying English so hard these days?”
中文想法我想跟外国人正常聊，所以最近在补框架和词汇
意图③ 解释（结论前置）
骨架X, so Y.
成句I want to talk with foreigners more naturally, so I've been practicing sentence frames lately.
外教：“Just book the expensive course—it'll be fine.”
中文想法万一上完还是没提升呢？钱就白花了
意图④ 担心
骨架What if X?
成句What if I finish the course and still don't improve?
外教：“Would you move abroad for work?”
中文想法只要家人没事、我还能常回来，我可以考虑
意图⑤ 底线
骨架As long as X, I'll Y.
成句As long as my family is okay and I can come back often, I'll consider it.
场景：你刚说了一半卡住——“I think the… uh… the thing is…”
中文想法重说：重点不是钱，是时间不够
意图⑥ 卡壳自救
骨架I mean… / In other words, …
成句I mean—it's not about the money. In other words, I just don't have enough time.
口袋

口袋卡 · 只带这 6 句上场

上课前花 2 分钟过一遍；课中卡住就扫这张卡。其余 50+ 框架全部留在手册里。

上场只带这 6 条

  1. 表态 → I know X, but Y.
  2. 选择 → I'd rather X than Y.
  3. 解释 → X, so Y. / …after all.
  4. 担心 → What if X?
  5. 底线 → As long as X, I'll Y.
  6. 卡壳 → I mean… / In other words…
💡 练习法：让外教 / 朋友用中文甩你一个日常问题，你强制 5 秒内只许用上表某一条回应。练的是「定意图」，不是背更多句型。
